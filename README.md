A 4 KB Python chess engine for make.fun's tiny-chess-01 bounty. 0x88 board, iterative deepening alpha-beta with PVS, LMR, null-move pruning, transposition table and quiescence. About 1367 Elo in local practice trials.

## Run it

```sh
python3 main.py
```

The engine plays through the make.fun env (MAKEFUN_ENV_URL). See the kit's grade-local for a full practice trial.
